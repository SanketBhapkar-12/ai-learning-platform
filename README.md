\# Adaptive AI Learning Platform



An AI-powered learning platform built with Java, Spring Boot, MongoDB, and Google Gemini API to support personalized learning.



\## Features



\- Course, module, and lesson management

\- AI-powered learning content generation

\- Quiz evaluation and learner performance analysis

\- Weak-topic detection based on quiz accuracy

\- Rule-based adaptive lesson recommendations

\- Lesson progress tracking and progress dashboards



\## Tech Stack



\- Java

\- Spring Boot

\- MongoDB

\- Google Gemini API

\- Maven

\- Postman

\- Git and GitHub



\## How It Works



The platform analyzes quiz results to identify weak topics, recommends relevant incomplete lessons, and tracks learning progress.



The current recommendation engine uses rule-based scoring rather than a trained machine-learning model.



\## Project Status



Backend development in progress. Authentication, automated behavior testing, the frontend, caching, asynchronous processing, and deployment are planned improvements.



\## Run Locally



Prerequisites: Java compatible with `pom.xml`, MongoDB, and the Maven Wrapper.



1\. Clone the repository.

2\. Configure MongoDB and the Gemini API key in your environment.

3\. Run the application on Windows:



```powershell

.\\mvnw.cmd spring-boot:run

```
